# Beauty Elite Academy セミナー LP

サロンオーナー向けセミナーの LP を管理するリポジトリです。La Viora の新規集客用 LP とは別に管理します。

## 表示パターン

- `index.html`：ひとりで回して、利益が残らない
- `index.html?ad=workstyle`：現場に立ち続ける

`ad=workstyle` を指定した場合に、ファーストビューの見出しと画像を切り替えます。それ以外のページ部分は共通です。UTM など他のパラメータを併用できます。

本番 URL の候補（未設置）：

- `https://seminar.laviora-clinical.jp/`
- `https://seminar.laviora-clinical.jp/?ad=workstyle`

## 構成・公開時の確認

このフォルダ内の `index.html` と画像ファイルを同じ公開フォルダに設置します。GitHub への保存時点では本番サーバーへの設置は行っていません。

元の確認ページに合わせ、ボタンはページ内の開催概要へ移動します。開催日時、会場、LINE 申込先は準備中です。配信前に開催情報、申込先、計測設定、素材の使用条件を確認してください。

画像と文章は共有された確認用 LP をもとにしています。
